# AutoLoc

## Description

AutoLoc est une application de gestion de location de voitures permettant
de faciliter la gestion des véhicules, des clients, des agences et des
locations.

## Acteurs

Le système AutoLoc comprend les acteurs suivants :

- **Client**
- **Agent d'agence**
- **Responsable d'agence**
- **Administrateur**

## Cas d'utilisation

### Client

- Consulter les véhicules disponibles
- Rechercher un véhicule
- Consulter les informations d'un véhicule
- Effectuer une réservation
- Consulter ses réservations
- Annuler une réservation

### Agent d'agence

- Gérer les réservations
- Enregistrer une location
- Enregistrer le retour d'un véhicule
- Consulter les informations des clients
- Consulter la disponibilité des véhicules

### Responsable d'agence

- Gérer les véhicules de l'agence
- Consulter les locations
- Consulter les réservations
- Consulter les statistiques de l'agence
- Superviser les activités des agents

### Administrateur

- Gérer les utilisateurs
- Gérer les agences
- Gérer les véhicules
- Gérer les paramètres du système
- Administrer les données de l'application
